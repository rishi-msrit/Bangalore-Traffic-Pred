Technical Analysis i This section covers the statistical and machine-learning layer of the project: a full correlation matrix across all numeric fields, a linear regression model predicting Congestion Level, k-means clustering of roads into behavioral archetypes, and per-road anomaly detection using z-scores.

Correlation, regression, clustering, and anomaly detection -- the full analytical layer.

This page is for those who want to see the methodology behind the numbers on the other pages. All computations were done once offline in Python and exported as static data -- nothing here runs live. The regression and clustering are supporting evidence for the narrative findings, not an end in themselves.
Correlation matrix
Pairwise correlations: all numeric fields i Pearson correlation between every pair of numeric columns. Values range from -1 (perfect inverse relationship) to +1 (perfect positive relationship). 0 means no linear relationship. Darker red = stronger positive correlation; darker blue = stronger negative correlation.

Model metrics
R squared
--
Proportion of variance explained (0 to 1, higher is better).

--
Average prediction error in congestion-level units (0-100 scale).
Target variable: Congestion Level (0-100 scale).
Model: ordinary least squares, all features standardised before fitting.
Coefficients reflect each feature's predictive contribution at equal scale.
Feature coefficients: sorted by absolute magnitude i After standardising all features, the coefficient shows how much Congestion Level changes per one standard-deviation shift in that feature. A larger absolute value means more predictive weight. Red bars are positive relationships; blue bars are inverse (negative) relationships.
Road clustering (k-means, k = 4)
Road archetypes: PCA scatter i Each point is one of the 16 roads. Position is determined by the first two principal components (PCA) of six road-level features: mean congestion, mean speed, capacity saturation, incident rate, traffic volume, and travel time index. Roads grouped by colour share similar behavioral profiles. PCA reduces 6 dimensions to 2 for plotting -- the axes have no direct unit interpretation.

Anomaly flags
Per-road congestion spikes (z-score above 2.5) i Each row is a date-road combination where the recorded Congestion Level was more than 2.5 standard deviations above that road's own historical mean. This flags genuine outliers relative to each road's baseline, not just high absolute values. A z-score of 2.5 means the observation sits in roughly the top 0.6% of that road's distribution.
